# Report skeleton: the default outline tree of a research report for decisions

ficc-outliner starts from here when it builds the tree at FICCHand step 5b (`references/outline-from-research.md`), then changes it by content; what follows is drawn only to section level, and each node must still grow down to paragraph groups (FICCOutline 4.1 step 5, 3.4): the tree grows by content and is not forced into neatness (FICCOutline 3.4); which overall structure is chosen, and why, is stated in one or two sentences in the outline header, with the reason tied back to the root claim (FICCOutline 2.1). Node format per FICCOutline 4.2; the order line writes the ordering reason, and the relation line waits for ficc-voice's relation sheet, see `references/outline-from-research.md`.

```
头：这次做什么（新写／更新，能否加新事实）；题目与目标；决策问题（用户原话）；体裁、读者、篇幅；必须保留；读者读完应明白什么；不做的事（不预测、无受托不写操作建议）；时间窗与数据截止日
## 名字表（由脉络图第6节来，FICCOutline 4.2）
## N0 根主旨
- **主旨**：对决策问题的判断（一两句）＋把握度和限制它的那一环；预测式的问题先改写成条件式
  N1 导语：读者的问题与答案；根主旨落在开头（FICCOutline 8.1）
  N2 发生了什么：时间线分段，每段的变化与转折（脉络图第2节）
  N3 为什么：主线的机制，按环或按参与方展开（脉络图第3、4节）
     N3.x 支线：挂在它服务的那一步下面，不另起一级，除非它能单独改变根主旨
  N4 容易读错的地方：分歧是要点时写分歧的状态；易混的两样在这里辨开（脉络图第6、7节）
  N5 影响：按条件写，触发—渠道—受影响者—信号—时间窗（脉络图第5节）
  N6 什么会改变判断：改判条件与观察清单，日期、阈值、同一口径（脉络图第10节）
  N7 相对上一版改了什么（更新类）：改结论的几条、只改程度的几条（脉络图第11节）
  N8 出处清单：机构、正文日期到日、报告名；不计篇幅（FICCOutline 4.2）
```

Common changes: give the most space to the step with the most evidence and the strongest pull between directions; when correcting a popular view, refute then build (first take apart its premise, then build our reading); for a topic that can be told clearly by time, merge N2 and N3 into an unfolding by segment; with no previous version, delete N7.
