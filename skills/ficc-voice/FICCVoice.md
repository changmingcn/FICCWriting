# FICCVoice: Write the relations clearly

FICCVoice writes the judgments settled by FICCOutline, FICCStructure and FICCCompose as clear, explicit, concrete sentences. Leave the reader nothing to take apart, pair up, or fill in logically. Decide sentence splitting and glossing by this standard, not by cutting at a character count. Use breakdown and checking for drafting and revising. They impose no fixed sentence pattern and add no fixed deliverable table.

## 1 Break the meaning down first

- **V01** **State this node's task concretely.**
  - Read the relation sheet, outline, name table, adjacent nodes' conclusions, and assigned material.
  - Against the parent node's claim, write which content this node uses to complete which step of that claim.
  - Name the sibling judgment it carries over from, and what it adds or limits.
  - State how the sub-items together complete this node.
  - Check: follow “支持、递进、并列” (support, progression, parallel) with concrete content. If the relation sheet does not give it, hand it back per V04.
- **V02** **Split mixed meanings into statements that can be checked one by one.**
  - When a long sentence or the material mixes facts, causes, forecasts, and measurement bases, split them item by item.
  - Write each item as “who/what, does what / is what / changes how”, with its time, conditions, negations, and source of judgment.
  - Per the relation sheet, identify the main judgment and the items that explain, support, limit, or illustrate it.
  - Delete only repetition.
  - Write simple material directly. For complex material, list a few temporary lines. Keep working labels out of the body text.
- **V03** **Attach each item to the judgment it actually explains.**
  - For each reason, piece of evidence, example, or counter-evidence, write which question in which sentence it answers.
  - Let an example show one case only.
  - When data show only correlation or sequence, do not write causation or mutual reinforcement.
  - Check: cover words such as “所以、可见、而且” (so, evidently, moreover) and look only at the two sides. You must still be able to say what makes this step hold. If you cannot, hand it back per V04.
- **V04** **State the gap clearly, and finish the conflict-free part first.**
  - When the relation is unclear, the material is insufficient, or the relation sheet contradicts itself, write the conflict-free part first.
  - Hand back the planned judgment or relation, how far the material actually supports it, and what is still missing. T0 forwards relation problems to the relation agent and placement, claim, or order problems to the outline agent.
  - Do not add causes, add facts, or pick one unsettled explanation for the sake of flow.
  - As the writer, do not change placement, claims, or node relations. Hand back any needed change per this rule.
  - In a style-only edit, keep the existing content and structure.
  - If a requirement such as a governing paragraph opening can be met only by changing order or structure, report it separately.
  - See V29: merge pure notes back where they serve. See FICCOutline.md 7.3: rewrite permissions.

## 3 Sentences and cohesion

- **V10** **Control sentence length.**
  - Prefer short sentences, provided the meaning stays complete and references stay clear.
  - First delete repetition and redundancy. Then judge whether the sentence needs splitting. Do not delete necessary conditions, scope, or exceptions to shorten a sentence.
- **V11** **Keep each sentence focused.**
  - Build each sentence around one main judgment or action. Conditions, scope, and exceptions that directly qualify that judgment may stay in the same sentence.
  - If a sentence contains several judgments or actions that need separate statement, split them into several sentences. After splitting, make sure each condition and qualifier still clearly maps to its original judgment.
- **V12** **Keep wording and reference consistent.**
  - When adjacent sentences discuss the same object, use a consistent name or key term. Avoid needless changes of wording.
  - When using referring expressions such as “这” (this), “它” (it), or “该情况” (this situation), make sure the reader can clearly identify what they refer to. Otherwise, write the specific name.
- **V13** **Make the logic between sentences explicit.**
  - When you need to express a relation such as cause and effect, turn, condition, or progression, first confirm that the source text or context supports it. Then choose the precise connective.
  - If the support is sufficient but necessary information is missing in between, supply the information first. Then connect the sentences. If the support is insufficient, you must not build the relation with a connective alone.
- **V14** **Revise by problem type.**
  - Check sentence by sentence, and apply the matching fix:
    - Unclear subject of a judgment or action: state the subject, or rewrite the reference.
    - Unclear necessary condition, scope, or exception: complete it or move it, and make clear what it qualifies.
    - Several judgments or actions crammed into one sentence: split the sentence, and keep each one's conditions and qualifiers.
    - Unclear relation to the preceding text: check whether information is missing and whether the order is sound. Then handle it per V13.
    - Complete meaning but wordy expression: delete redundancy, and split the sentence when needed.
  - The check guides revision. You need not show the checking process in the output.
- **V15** **Write the action and who performs it, then choose active or passive.**
  - Reading a sentence, you can find who or what is in what state, did what, and mainly shows which point.
    - Within a simple sentence, require only a clear sentence core and clear attachment of modifiers.
    - Where the outer and inner markers of a multi-layer complex sentence go: per V54.
  - Rewrite phrasings such as “进行分析、实现改善、承担风险” (conduct analysis, achieve improvement, bear risk) as who did what to what.
  - State which quantity moved in which direction. Use the subject and the concrete verb that the material gives.
  - Keep subject, action, and object close. Do not let sources or long explanations break the sentence core.
  - When only “有影响” (has an effect) is known, keep the known scope. Do not add direction or magnitude.
  - Before changing a passive sentence, find who or what caused the event. If the agent is known and matters, state it.
  - If the agent is unknown, or you want to keep the patient as the topic, you may keep the passive.
  - When the same company changes role along the chain, state which role it plays in this sentence whenever you write about it.
  - When saying “损失” (loss), “赔” (lose money), or “扛” (bear), you must say which party.
  - Do not merge several parties' responsibilities into one subject.
  - Do not put one party's financial-statement distortion and another party's debt risk into the same judgment.
  - Check: circle every “赔”, “损失”, “扛”, and “低估” (underestimate) in the text and find which party is its subject. If you cannot answer, or the answer is two parties, write them separately.
- **V16** **Unpack relations compressed into nouns and modifiers.**
  - Make it determinable which action or judgment each condition, cause, example, added explanation, aside, and source modifies.
  - For stacked attributives or long noun phrases, find the head first.
  - Then identify whether each remaining word says whose, toward whom, for what, or when.
  - Where two connections are possible, use a preposition, a verb, or a clause to state the one that the material settles.
  - If the material does not settle it, verify first.
  - A mechanism sentence may run several steps, a comparison several parts, a judgment its conditions and reservations. Do not force every sentence into one subject–verb–object template.
  - For “如果A，那么B，但只有C时才成立” (if A, then B, but only when C holds), state whether C limits B or the transmission from A to B.
  - Where a long attributive embeds another matter, lift the needed explanation into a clause and reconnect it to the sentence core.
  - Start a new sentence for an explanation only when it is a step in the argument.
  - Standard terms and official names stay whole (V32).
  - Place words such as “仅、主要、可能、短期” (only, mainly, possibly, short-term) next to what they actually qualify.
  - Where a change of subject or an omission could cause a wrong carry-over, rewrite the name.
  - Use omissions that can be restored uniquely.
- **V17** **Confirm the logic of the conditions first, then write conditions and results fully paired.**
  - List which conditions limit each result.
  - Settle whether all conditions must hold or any one suffices, and whether each is necessary or sufficient. Then choose the form:
    - One set of conditions for one result: join the object it applies to, the conditions, and the result.
    - One set of shared conditions for several results: write the shared conditions first, then each result.
    - Several conditions for one result: write “同时满足A和B” (both A and B are met) or “满足A、B任一项” (either A or B is met) explicitly. Do not rely on the enumeration comma (、) alone.
    - Several sets of conditions for different results: restate the subject and the applicable conditions for each item.
  - Attach any extra condition of a single result to that item.
  - If the reader would still need to match back and forth, use an “对象／条件／结果” (object / condition / result) table.
  - Keep “分别” (respectively) only when the mapping is visible at a glance.
  - Suppositions and conditions carried by “如果” (if), “一旦” (once), or “只要” (as long as), and their consequences, stay hypothetical. Do not let rewording turn them into fact.
  - Do not replace “只有” (only if) with “只要” (as long as), or “不超过” (no more than) with “等于” (equal to).
  - Check: pick any result. You can find all its conditions and exceptions at once.
- **V18** **Make both sides of a comparison directly comparable.**
  - First check the indicator definition, object scope, point in time, base period, and unit.
  - Build only one directly comparable comparison per sentence. When the indicator, base period, or object changes, state a new comparison.
  - Distinguish level from change, amount from ratio, and percent from percentage point.
  - After “更高、更快、也一样” (higher, faster, likewise), name what is being compared against.
  - Check: the reader can answer directly “whose what, compared with whom or which period, changed how”. If an element is missing, state what these figures cannot compare. Do not guess the measurement basis.
- **V19** **Make punctuation carry a definite relation.**
  - Before a colon (：) or dash (——), state a complete judgment. Every following item must explain, prove, or list part of it. Write unrelated details separately. If the judgment involves several subjects, keep their actions, responsibilities, and facts distinct.
  - Do not let a comma (，) hide an unannounced change of subject.
  - Check: treat the sentence before the colon or dash as a question.
    - Then read the items after it one by one, and see whether each answers it.
  - Move an item that does not answer it to after the sentence it really answers, or delete it.
  - Check: after changing punctuation or splitting a sentence, reread conditions, negations, and comparison targets. If their scope has changed, restore the original object or rewrite the whole sentence. Do not just swap the symbol.
- **V20** **Check the strength of judgments before and after rewriting.**
  - Map qualifiers in the source such as “可能、预计、多数、短期、约、不超过” (possibly, expected, most, short-term, about, no more than), together with their objects, into the new text.
  - Before changing a double negative, check the object, scope, or degree of the negation.
  - “并非所有” (not all) must not become “都不” (none). “并非不可能” (not impossible) must not become “必然” (certain).
  - When evidence is missing, write only that no judgment can be made. Do not write it as proof of the opposite conclusion.
  - You may point out an error in the original judgment.
  - Check: if a qualifier is lost, the scope widened, or the speaker changed, restore it.

## 4 Cohesion: which words mark the relations

### 4.1 Which connective to use

- **V21** **Establish the content relation first, then choose the connective.**
  - Words and relation classes: references/connectives.md 1.
  - Keep exemplification distinct from proof, explication from progression, and supposition from condition. Do not change the relation by swapping words. Relation diagnosis: FICCStructure.md S04, S18, S27.
  - When the material supports only side-by-side observation, set the observations side by side. Do not add a connective that implies more relation than that.

### 4.2 Use enough, do not pile up

- **V22** **Make the relation at each seam visible to the reader, especially turn, cause and effect, condition, limitation, and concession.**
  - Do not omit the latter-clause relation marker.
    - “因为、虽然、如果” (because, although, if) in the former clause may be omitted.
    - Do not omit the connecting “但是、所以、就、才、也、还、却” (but, so, then, only then, also, still, yet) in the latter clause.
    - Add a former-clause marker only when the relation needs to show early.
    - In a pair, when both clauses share a subject, put the former-clause word after the subject. When the subjects differ, put the former-clause word before the first subject.
  - Do not mechanically repeat the same word in adjacent sentences.
  - Do not let transition fillers such as “值得注意的是” (it is worth noting that) or “进一步来看” (looking further) stand in for a relation.
  - Replace a vague clause-initial “而、则、并、且” (and/while, then, and, also) with a word that states the relation; fixed words are exempt (references/connectives.md 6).
  - Numbering inside a sentence or at a paragraph opening: references/connectives.md 6, FICCCompose.md C10.
  - Check: after writing, look first for the most often missing ones: inference, “但是” (but), progression, concession, explication, back-reference, and “甚至” (even) and “其实” (actually).
  - In a paragraph opening and a node's opening sentence, show the relation at the very start: choose a connective or a naming back-reference by the settled relation (relation sheet) and the paragraph arrangement (FICCCompose.md).
    - The relation is to the level above and to the sibling it follows. By default, the sibling it follows is the previous one. When it follows an earlier one, name that one with a back-reference.
    - There are two ways to show it (the user's two edits of 2026-10-14: references/examples-and-rewrites.md, Revision example 4):
      - Put a connective that states the relation at the start of the sentence, with the named judgment as the subject.
        - Or state the answer once first, then open the next sentence with “但是” (but) to state the limit.
      - Start the sentence with a back-reference that names which judgment or which thing it follows (wording: 4.3).
    - Choose the word by relation from references/connectives.md 1: turn “但是、不过” (but, however); cause and effect “所以、因此” (so, therefore); conditions and limits “只是” (only) or “但……只有” (but… only when); concession “虽然” (although); progression “而且、更” (moreover, even more).
    - The relation to the level below is carried by preview and payoff (FICCCompose.md C20), not marked at the sentence start.
    - How to write the subject: see 4.4.
  - At an opening, these four relations must not go unmarked: turn, cause and effect, conditions and limits, and concession.
    - Only two cases allow no connective:
      - The sentence continues the earlier text in a straight line.
      - It is the opening sentence of the first child node under its parent, or of the first item in a group, and it states the heading's claim.
    - Turn includes light turns.
    - Hinting the relation by re-mentioning a few words of the previous paragraph does not count as marking.
  - Check: read only the first few characters of each paragraph-opening sentence and node opening sentence. They show its relation to the level above and to the sibling it follows.
  - Check: after writing a paragraph, run each seam through the seven checks below. Where a seam fails, fix the wording if wording can fix it. Do not pad with added words.
    1. Preview and payoff: FICCCompose.md C20.
    2. Each same-layer seam carries a word of the class the relation sheet names (the proposition is the relation agent's check, FICCStructure.md S90; the word is the writer's).
    3. Back-test each marked word against its row in references/connectives.md: what precedes “所以” (so) must be a cause, what follows “而且” (moreover) must go one layer further, and the two sides of “但是” (but) sit on the same dimension. Where inference belongs, “既然、可见” (since, evidently) is present. A “因为” (because) or “所以” that only restates or splits the first half: FICCStructure.md S28.
    4. Latter-clause markers not omitted, and the relation of each paragraph opening and node opening sentence shown: this rule.
    5. The antecedent of paragraph-opening and sentence-opening connectives: V53.
    6. Suppositions and conditions stay hypothetical: V17.
    7. Items after a colon or dash: V19.
- **V52** **Put connectives at the seam between two things.**
  - After the reader's question in the lead, place a back-reference or add-on marker (references/connectives.md, row 并列·附加关系).
- **V53** **Keep a connective right next to its true antecedent.**
  - A paragraph-opening connective connects to the previous paragraph's claim or close, not to its last example.
  - The same holds for linking-back sentences above section level: they gather the whole preceding story and push forward from the preceding paragraphs' conclusions.
  - Where an inserted sentence or route sentence sits in between, move it away.
  - When the true antecedent is not adjacent and the order is fixed by the relation sheet, use a named back-reference instead of a connective.
  - Check: the sentence right before each paragraph-opening and sentence-opening connective is its true antecedent.
- **V54** **When two layers of relation nest, put the outer layer's word at the outer seam and the inner layer's word at the inner seam.**

### 4.3 Back-reference and the same word

- **V23** **Keep the same name pointing to the same object.**
  - After intervening material, or when carrying over from an earlier sibling, name the object again.
  - For a concept with a count, list all its members at first mention. Do not silently change the referent later.
  - Check: replace each “这、它、前者、上述” (this, it, the former, the above) with the full name. Where two objects fit, change it to a naming form such as “这笔贷款、这一偿还义务” (this loan, this repayment obligation). Where no antecedent can be found, reintroduce the object.

### 4.4 Given–new

- **V24** **Lead from an established object to the next new information.**
  - Find the object or judgment to carry over from in the finished draft, per the relation sheet.
  - Do not treat information that is in the notes but not yet written into the draft as known to the reader.
  - Put the added state, action, or limit after it.
  - When the main judgment can be understood only after a new object, introduce that object and its role first. Then give its attributes.
  - The introduction may sit inside the sentence. If the two interfere, use a separate sentence. Handle pure notes per V29.
  - Necessary points in time, conditions, and relation markers may come first.
  - Do not build passives or repeat whole sentences for the sake of a fixed word order.
  - Do not hang a topic first and then switch subjects. Do not open with “X和Y是什么关系，材料没说” (what the relation between X and Y is, the material does not say).
  - Write first which judgment the gap limits. Then write what the material lacks.
  - When analysing the sources themselves, the sources and the question may be the focus.
  - Make the subject the thing this sentence judges, with its full name:
    - Do not use “这个回答” (this answer) or “这一点” (this point) as the first subject, except right after a preceding sentence that states it in full.
  - Check: sentence by sentence, confirm that the reader knows what each name refers to and can say which earlier point this sentence picks up from.
  - Relation at the opening: V22.

### 4.5 Parallel syntax

- **V25** **Use similar syntax to show items that truly correspond.**
  - When several parallel items are discussed separately, each number governs one thing, and the items share one basis of division.
  - First identify the question the items answer together. Confirm that they sit at the same level and on the same dimension.
  - Then write each item in a similar order, such as “subject, action, result” or “condition, applicable result”.
  - If one item has an extra condition, add it as it is. If data are missing, state the gap.
  - Do not delete limits or invent items for the sake of symmetry.
  - Do not line up a cause, its example, and its result as three same-level items.
  - After a long group, state together what the items mean for the current question. Do not force a tie-back onto a short group.
  - Group size: FICCStructure.md S25.

## 5 Terms, parentheses, and figures

### 5.1 Terms, parentheses, and figures

- **V26** **Let the reader identify each number as whose what.**
  - Where a number is first really used, state whose indicator it is, which indicator, the point in time, and the unit.
  - In the same place, state the measurement basis and any needed sample source.
  - Within a paragraph, a short name with unchanged meaning may be used. Do not redefine the same measurement basis repeatedly across the piece.
  - The base period and scope that the current comparison needs must be directly identifiable.
  - In new writing, verify against the original document where one exists. If the original does not say, leave the gap.
  - In a style-only edit, do not compute new numbers or fill blanks in the original. List doubtful points as to be verified.
  - For a fact to be verified, the writer writes sentences without it or leaves a blank. The body text carries no “待补充” (to be supplied) or “待核实” (to be verified) labels. Labels go only into the writer's result sheet.
  - Do not use deposits, reserves, capital, cash, and liquidity interchangeably.
  - Keep stock and flow, total and increment, and book value and market value apart.
- **V27** **Make the point the subject. Hang the source after it.**
  - Arrange sentences around the object and judgment being argued. Do not report material institution by institution.
  - By default, put the source at the end of the sentence it supports, as a parenthetical with the institution and the date to the day.
  - For a number from one institution's own method or measurement basis, write the source as an adverbial of that number.
  - When several institutions support the same judgment, a combined citation may be used.
  - Put report titles and details in the source list.
  - The body text carries a short title in only two cases:
    - Two reports from the same institution on the same day need to be told apart.
    - The title itself is the point being made.
  - Across articles, refer by issue number. Across sections, refer back by name.
  - When citing your own earlier articles and rules, refer back only with real grounds.
  - Move the sources for the lead and for each layer's opening to where the later text gives the evidence.
  - Without a publication date, use the day-precise date in the list. Failing that, use the collection date and mark it “收录” (collected).
  - Do not guess the missing parts of a date. Across years, write the year.
  - Check: where an argument paragraph uses institutions as subjects one after another (“X说……X还说……”, X says… X also says…), rewrite it with the point as the subject and the source in a parenthetical at the end of the sentence.
- **V28** **Do not let the attribution of views disappear in rewriting.**
  - You may keep “X说／认为” (X says / believes) in these cases:
    - A single institution's view that the article does not adopt.
    - Divergent views.
    - A full-sentence direct quotation.
    - Institutional actions such as forecasting or revising numbers.
  - Decide adoption per the outline and the relation sheet. When unsure, keep the speaker.
  - Merge quotations of one or two words into the judgment.
  - Do not strip the source from one institution's judgment and turn it into the article's judgment. Keep the source text and our inferences apart.
- **V29** **Decide first whether it is a note, then where to put the parenthetical.**
  - Count as a note anything that only identifies a word, glosses it, gives an alias, or identifies a source, and adds no premise to the argument.
  - Separate main and subordinate between sentences. A note does not count as a step in a sentence group.
    - Do not stuff two independent judgments into one long parenthesis as if both were supplements.
  - Attach a pure note once, where it serves. Do not make it a separate sentence. Attach notes for two words in two places.
  - A short gloss may merge directly into the sentence (first use: V32).
  - At a key noun's first appearance, you may add one plain-language parenthetical.
  - Do not use any other in-sentence parenthetical to explain a term.
  - Place a parenthetical after the word. If it does not fit there, place it after the sentence's full stop (。).
  - Place aliases, English names, and “下称” (hereafter) after the word.
  - Write measurement basis, sample, and period first as an attributive or adverbial of the number. Use a parenthetical only if they do not fit.
  - Handle sources per V27. Put a figure's measurement basis in the figure note, without parentheses.
  - A note is an argument step when its definition is this paragraph's core, the next sentence must build on it, its measurement basis decides the conclusion, or this paragraph must explain why it holds: unfold it per the relation sheet, and do not hide important premises, counter-evidence, or new points in parentheses.
  - Merging a pure note back where it serves counts as a wording change. Keep facts, qualifiers, and degree words as they are.
  - Check: mark the notes when checking.
  - Check: assume the reader knows the word, drop the explanation, and read on. If the later text still needs a fact or condition from it, or dropping it widens the main judgment's scope, move it into the body text as an argument step; if “样本内” (within the sample) would read as “全部” (all) or “可能” (possibly) as “确定” (certain), move the limit back into the judgment.
- **V30** → V29
- **V31** **Make figure, figure note, and body text match.**
  - Prefer a figure title that states a finding the data support. Distribution or measurement-basis figures may have descriptive titles.
  - Paragraph organization: FICCCompose.md C22.
  - Use the same object, period, and comparison baseline in the figure, the figure note, and the body text.

### 5.2 Wording the reader need not decode

- **V32** **Explain the one point the reader lacks. Do not let a term stand in for a mechanism.**
  - For the V34 reader, you need not re-explain basic financial knowledge item by item.
  - Explain definitions, measurement bases, and ambiguous words specific to this piece at their first actual use.
  - Explain until the reader can keep reading, and stop there.
  - Where everyday words can state the action and the mechanism, say it plainly. Use necessary standard terms as they are.
  - Take names from the outline's name table:
    - The table holds only coined nouns and nouns with several variant names.
    - The table has four columns: 名字 (name) ｜ 指什么与口径 (referent and measurement basis) ｜ 本篇写法 (form used in this piece) ｜ 不许用的叫法 (forbidden names).
    - The outline agent maintains the table.
  - Every name in the body text is either in the table or a standard term. Send new names outside the table through T0 to the outline agent, which rules on them and maintains the table.
  - Use market names. For same thing, same name, see V23.
  - Do not replace indicators, data series, or groups with coined short labels.
  - Allow at most one coined name per piece. Introduce it in the lead, explain it on the spot, and keep using it.
  - In sentences with numbers, still use the indicator name.
  - Where a forbidden word in the name table carries a condition, judge by that condition.
  - Use few terms:
    - Put few new nouns in one paragraph. The fewer kinds, the better.
    - For plain-language parentheticals, see V29.
    - When something is hard to explain, give the reasoning first and the name after (“这种手法，我们叫做……”, this technique we call…).
    - Draw comparisons from things the reader has experienced.
    - Do not insert encyclopedia entries. Use the topic word directly. Do not gloss it repeatedly.
  - Do not give names to views or mechanisms. Use everyday verbs:
    - For other people's views, write who holds them and what they believe. Do not compress them into “对手的读法” (the opponent's reading).
    - State a mechanism in full the first time. Afterwards refer back with a phrase such as “这两条规则” (these two rules). Do not coin a code name.
    - Do not apply “收敛、付价、标零、兑现” (converge, pay the price, mark to zero, cash in) to economic facts.
    - Do not let “读数、口径” (reading, measurement basis) appear in place of the numbers and the method.
- **V33** **Choose terms, abbreviations, and names by whether the reader can identify the object.**
  - Choose a name and its language in this order: the name table's ruling (FICCOutline.md O32–O33); then the language rule after the table (O33), which also governs standard terms the table does not list; only where both leave the choice open, the readability choice below.
  - Institution names: per the list after the outline's name table (FICCOutline.md O33).
  - Use a Chinese word where readers understand it more easily.
  - Do not make the reader look back repeatedly for definitions to understand one sentence.
  - See references/lecture-terms.md: lecture terms.
- **V57** **Views and inferences are not objects.** A view, reading, explanation or inference is never the subject or object of a verb that moves it: it does not “加强、变轻、占上风、站在一边、并存”, and it is not counted (“三种读法”). Write who holds it and what they believe (“Barclays看成技术性抛售”), or what we think (“我们认为”, “在我们看来”, “更像是先后”); when several views stand side by side, write “三种说法” once and name each holder. No label for an interpretive move of ours: 读法, 解读, 视角, 框架, 判别读数 and the like are out even when the outline carries them — the outliner translates such words before they reach a claim line (FICCOutline.md O91). Check: grep the node for `读法|解读|视角|判别读数|推断加强|判断.{0,4}加强|占上风|站在.{1,8}一边` and read each hit; a hit whose subject is a company, a house, a price or 我们 passes; `voice_check.py --clarity` lists the hits as review candidates (H9), never as hard faults. 框架 is read by eye: in house drafts it is a deal or policy term.

## 6 Metaphors, characters, jokes, and hooks

- **V34** **Write for the default audience in the right writing persona.**
  - The default audience is practitioners with a master's background in finance or economics who know basic financial concepts.
  - Publish as the author. Your own style is allowed. Imitating model texts is not required. Correct per user feedback.
  - Use “我” (I) for real first-hand experience. Use “我们” (we) by default in argument. Use “你” (you) when working through how the reader would choose.
  - State any change of condition or persona explicitly.
  - When writing in someone else's name, adopt that person's persona. Do not invent trades, positions, research visits, client conversations, or past judgments.
  - Say explicitly that a hypothetical scene is hypothetical.
- **V35** **Make metaphors, characters, and jokes serve the current question.**
  - Explain the mechanism first. Then use a metaphor to help the reader follow the specific channel.
  - For an analogy, state the dimension of similarity and its limits. Do not derive from a metaphor a conclusion the material does not contain.
  - Handle coined names per V32.
  - Handle first-hand experience per V34.
  - Paragraph organization: FICCCompose.md C21.
  - Aim criticism at claims and mechanisms. Do not make fun of client losses.
- **V36** **Convert to written register while keeping information, analysis, and personality. Do not write officialese.**
  - Remove classroom cues and useless restatement.
  - Lecture notes may use more characters and dialogue. Specific cases may switch back to report style.
  - Set no minimum for personal pronouns and no quota for jokes.
  - Use parallelism and strong words only where the content needs them. The second half of “不是……而是” (not… but…) must have concrete grounds.
  - Do not change original sentences that the author designated to keep verbatim.
  - See references/written-register.md: transcript details.

## 7 Check before submitting

- **V37** **First use the finished draft to test whether the reader must do organising work.**
  - Without the material or the relation sheet, using only the finished draft and the name table:
    - Read paragraph by paragraph. State each sentence's object, judgment, conditions, and the layer above that it serves.
  - Paragraph openings and the openings check: FICCCompose.md C23.
  - Every place lets the reader know three things:
    - What is being said now.
    - Why it is said here.
    - How the following text makes it clear.
  - Check: after reading a local passage, you can state its main meaning and why the next sentence connects here.
  - If you cannot, first handle mixed layers, stray material, missing premises, false turns, and unclear references, then revise the wording.
  - Mark the following obstacles, then fix that spot:
    - Responsibility can be matched only by rereading.
    - A pronoun must be guessed from among several names.
    - The reader must supply causes or regroup content for the author.
  - Avoid AI tone: check each paragraph for the following six. Fix them where they cluster. Handle a single occurrence per its own rule.
    - Roadmap sentences: FICCCompose.md C01, C06 (script H2).
    - Hollow claims: FICCCompose.md C02, V38, V36.
    - Template tone (every paragraph shaped the same): FICCCompose.md C09, C11, C19.
    - Term pileups: V32.
    - End-of-paragraph uplift: FICCCompose.md C17, C19 (script density row 段末升华).
    - Transition fillers: FICCCompose.md C17, V22 (script density row 本质上等五词).
  - See references/FICCVoice-rationale.md V37.
- **V38** **Then check both ways, from material to new text and from new text to material.**
  - For each meaning split out per V02, find its new location.
  - Lose no judgment, fact, number, base period, condition, exception, negation, degree, or attribution, and do not shift any of them to another object.
  - Check the new text back sentence by sentence. Every added action, causal word, generalisation, and note of certainty must have grounds.
  - In a complex reorganisation, you may temporarily mark new locations beside the source sentences. Stop once the check is done.
  - Finally, look specifically at split and merged sentences, and check each item:
    - Whether a shared condition now governs only the first sentence.
    - Whether an exception wrongly extends to everything.
    - Whether several subjects' responsibilities have been merged.
  - Then check subject–predicate fit, modifier placement, and missing characters.
  - The writer fixes wording problems.
- **V39** **Handle script flags by comprehension obstacle, not by driving counts to zero.**
  - When a flag such as clause count or noun-string length fires, check each item:
    - Whether the sentence core is interrupted.
    - Whether a condition must be matched back.
    - Whether a modifier can be read two ways.
  - When you find a problem, fix the matching expression. If you cannot name a misreading or a comprehension load, keep the text and state why.
  - Even when counts stay within limits, still check for missing relations, missing conditions, and wrong attribution.
  - Do not lower counts by deleting qualifiers, hiding them in parentheses, or switching to abbreviations.
  - The paragraph length cap (FICCCompose.md C08) is a hard limit. This rule covers only the script's other flags.
- **V40** **Report reading problems that can be located and fixed.**
  - Writer: cold-read your own node before submitting. After the draft is assembled, a separate cold reader reads with only the finished draft and the name table (dispatch: SKILL.md 2).
  - The cold read reports only and does not edit. For each spot, list the node, line number, original sentence, and matching rule.
  - For each spot, write what it might be misread as or what must be looked back for, and where the text is actually lacking.
  - Mark A for a likely misreading and B for slowed reading. Do not report only “长、绕、不顺” (long, convoluted, not smooth).
  - Resolve both kinds of real problems before submitting. Send uncertain ones to T0. Give a reason for each false alarm.
